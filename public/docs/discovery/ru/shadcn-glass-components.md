# Стеклянные компоненты через shadcn.

> Добавьте редактируемые React-компоненты tenvell через shadcn CLI: рабочий пример кнопки или всё ядро, стили в своей области и локальные шрифты.

Shadcn CLI копирует стеклянные компоненты tenvell в проект на React 19. Вы получаете редактируемые исходники, стили в своей области и оригинальные шрифты Lamina. Начните с небольшого рабочего примера или установите ядро, если экрану нужны разные семейства компонентов.

## Один пример или всё ядро

Элемент button-demo устанавливает рабочий пример кнопки и её настоящую зависимость с кнопкой и провайдером. Элемент tenvell устанавливает публичный модуль ядра: из него можно импортировать несколько семейств компонентов.

У отдельных элементов собственные пути импорта. После button.json импортируйте Button, Input, Textarea и TenvellProvider из своего модуля components/tenvell/button. Общий файл стилей подключается один раз.

## Поиск компонентов через агента

Добавьте шаблон URL для @tenvell в существующий components.json. Официальный shadcn MCP сможет перечислить и найти элементы registry, показать примеры и вернуть команду установки.

Registry публикует настоящий код компонентов и их зависимости. Для просмотра возможностей агент также может использовать компактный список компонентов и Markdown-справочник API.

## Исходники остаются в вашем проекте

CLI записывает файлы в настроенный алиас компонентов. Сохраните алиасы проекта и проверьте запросы о замене существующих файлов. Стили tenvell ограничены провайдером и его слоями; при распространении копий сохраняйте лицензии кода и шрифтов.

## Подойдёт, если

- В проекте на React 19 уже настроен shadcn.
- Нужны редактируемые стеклянные кнопки, карточки, поля, меню и диалоги.
- Вы хотите читать исходники и менять оформление внутри приложения.

## Перед установкой

- Сам tenvell использует обычный CSS. Если другим элементам проекта нужен Tailwind, сохраните его настройки.
- Отдельный элемент не создаёт общий модуль ядра: используйте его собственный путь импорта.
- Официальный MCP запускается в контексте проекта пользователя и читает его components.json.

## Начните в своём проекте

```sh
npx shadcn@4.23.0 add https://tenvell.space/r/button-demo.json
```

## Частые вопросы

### Нужен ли отдельный MCP-сервер для tenvell?

Registry работает с официальным shadcn MCP. Добавьте @tenvell в целевой проект и настройте клиент по официальной инструкции.

### Можно ли установить пакет без копирования исходников?

Да. На странице установки также доступны опубликованный HTTPS-архив пакета и стартовый проект с lockfile.
